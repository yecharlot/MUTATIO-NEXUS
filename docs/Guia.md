# Guía rápida

Soy el autor del proyecto. Esta guía es para el equipo.

1. Abre la URL pública o `http://127.0.0.1:4050`.
2. Mira la intro o pulsa **Omitir introducción**.
3. **Entrar / Registro**: elige comunidad (Científicos, Constructores, Guardianes). Recibes **100 CBN** iniciales.
4. Lee **Acontecimientos** y crea una **propuesta** (cuesta 2 CBN).
5. **Vota** (+1 CBN). Cuando haya votos, **Resolver**.
6. Si se aprueba y hay recursos/CBN, el **mapa** y los **indicadores** cambian; nace un post social.
7. Consulta la pestaña **CBN** para el historial.

Todo cálculo económico ocurre en el **servidor**. El navegador solo muestra estado.
