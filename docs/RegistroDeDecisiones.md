# Registro de decisiones

1. **Stack**: Node + Express + SQLite MVP + front vanilla para control visual total.
2. **Reglas solo en servidor** (`rules.js`) para evitar trampas en el cliente.
3. **CBN interno** sin pasarelas ni wallets reales.
4. **Narrativa Atlantis**: hipótesis ficcional; no se presenta como hecho científico.
5. **Isométrico 2D + canvas**, sin WebGL pesado.
6. **PrismaTEC / Alset**: puntos de extensión futuros, sin dependencia obligatoria en el MVP.
