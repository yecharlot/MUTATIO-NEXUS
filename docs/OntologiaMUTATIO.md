# Ontología MUTATIO

- **MUTATIO**: red de mundos persistentes.
- **NEXUS**: primer universo.
- **Mundo**: instancia jugable (Cuba — El legado de la isla).
- **Comunidad**: Científicos, Constructores, Guardianes.
- **Recurso**: energía, alimentos, materiales, conocimiento, influencia.
- **Indicador**: estabilidad, alimentación, energía, infraestructura, confianza, tecnología.
- **Acontecimiento**: situación del mundo.
- **Propuesta / Voto / Resolución**: ciclo político-económico.
- **CBN**: unidad de cuenta interna (no dinero real).
- **Misterio**: evidencia e interpretación abierta (no se afirma Atlantis como hecho).
